# Dataset Documentation

## Overview

The detector uses multiple text sources to train and evaluate provenance classification across three classes: `human`, `ai`, `hybrid`.

## Human Data

Naturally written text, used as the baseline for comparison against AI-generated and AI-modified writing.

## AI Data

Text generated by language models — both locally generated samples and samples from external datasets.

## Hybrid Data

Human-written text modified by AI, at three intervention levels:

### Light
Grammar corrections, awkward-phrasing fixes, limited word-choice changes, removal of obvious repetition. Meaning and structure remain largely unchanged.

### Moderate
More substantial editing: grammar, clarity, sentence flow, word choice, conciseness. Original story, facts, and paragraph structure preserved.

### Heavy
Substantial rewriting of wording and sentence structure, while preserving underlying meaning and factual content.

## PERSUADE Data

PERSUADE 2.0 is integrated into training. Human PERSUADE samples are registered as human provenance; hybrid samples derived from them are registered separately and retain their original human source identifier.

## HC3 Data

Used as another source of human and AI text, and for building external evaluation material kept separate from the main training pipeline.

## Provenance Metadata

Training metadata fields: `essay_id`, `label`, `source`, `topic`, `generation_model`, `generation_prompt`, `human_editing`, `ai_intervention_level`, `source_group`, `split`, `author_language_background`, `notes`.

`ai_intervention_level` values: `none`, `light`, `moderate`, `heavy`, `full`.

### Source Groups

Hybrid samples derived from the same human essay share a `source_group` — e.g. Human Essay 001 → hybrid light / moderate / heavy. These are not independent original documents.

### Edit Ratio

```text
edit_ratio = 1 - similarity(original, modified)
```

using Python's `SequenceMatcher`. `0.0` = identical texts, closer to `1.0` = larger difference.

## Dataset Validation

Checks metadata and file consistency before use downstream — preventing missing metadata, invalid labels, inconsistent provenance info, missing text files, and malformed training records.

## Data Leakage Consideration

Because hybrid variants share a source group with their original human essay, a random row-level train/test split can let closely related variants of the same source appear across different partitions. Splits should be source-group-aware.
